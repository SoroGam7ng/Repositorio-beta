# Repositorio-beta

1. `git clone https://github.com/SoroGam7ng/Repositorio-beta.git` (Clonamos el repositorio en el ordenador)
2. (Entramos en la carpeta del proyecto, en nuestro caso manualmente desde VSC)
3. `git branch frontend` (Creamos la rama para el HTML)
4. `git branch backend` (Creamos la rama para el Java)
5. `git checkout frontend` (Cambiamos a la rama frontend)
6. `git add calculadora.html` (Preparamos el archivo HTML para el commit)
7. `git commit -m "Añadido archivo calculadora.html"` (Guardamos los cambios en el historial de frontend)
8. `git push -u origin frontend` (Subimos la rama frontend a GitHub)
9. `git checkout main` (Volvemos a la rama principal)
10. `git checkout backend` (Cambiamos a la rama backend)
11. `git add Calculadora.java` (Preparamos el archivo Java para el commit)
12. `git commit -m "Añadido archivo Calculadora.java"` (Guardamos los cambios en el historial de backend)
13. `git push -u origin backend` (Subimos la rama backend a GitHub)
14. `git checkout main` (Volvemos a la rama principal)
15. `git merge frontend` (Fusionamos el contenido de la rama frontend en main)
16. `git merge backend` (Fusionamos el contenido de la rama backend en main)
17. `git add README.md` (Preparamos el archivo de documentación)
18. `git commit -m "Documentacion de comandos en README.md"` (Guardamos la documentación en main)
19. `git push origin main` (Subimos todos los cambios finales a la rama main de GitHub)
